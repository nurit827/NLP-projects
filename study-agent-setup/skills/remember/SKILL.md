# Remember a slide

Add the current study slide to `exam/slides-to-review.md`.

1. Infer the current deck and slide number from the active study conversation. If either is unclear, ask one focused clarification question.
2. Read the collection before editing it and avoid duplicate entries for the same deck and slide.
3. Append a concise entry containing:
   - date;
   - lecture and subtopic;
   - deck path relative to `exam/`;
   - slide number and title;
   - why it should be revisited;
   - at most two key formulas or ideas.
4. Point to the original slide; do not transcribe the full slide.
5. Confirm briefly what was saved.
